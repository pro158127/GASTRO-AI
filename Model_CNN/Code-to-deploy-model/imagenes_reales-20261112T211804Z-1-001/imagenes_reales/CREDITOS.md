# Créditos de las imágenes de verificación

Los archivos de imagen de esta carpeta son una selección de EGID, GastroHUN e HyperKvasir. Se cambiaron sus nombres de archivo para crear el conjunto de verificación; no se incluyen rutas originales, identificadores de pacientes ni otra metadata de origen. El CSV conserva únicamente el nombre nuevo, el dataset de origen y las etiquetas usadas para evaluar.

## EGID

Zeyu Li, Yingying Fang, Yiming Song, Haotian Bai, Tianhao Li, Yaqi Wang, Qingwei Zhang y Xiaobo Li. *EGID: A Comprehensive Multi-label Endoscopic Image Dataset for Gastritis Classification*, partes 1 y 2. DOI: [10.6084/m9.figshare.30997345](https://doi.org/10.6084/m9.figshare.30997345) y [10.6084/m9.figshare.30996127](https://doi.org/10.6084/m9.figshare.30996127). Licencia: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

## GastroHUN

Diego Bravo, Martin Gomez, Juan Frias, Carlos Martinez, Felipe Vera Polania, Fabio A. Gonzalez, Eduardo Romero y Juan Naranjo. *GastroHUN an Endoscopy Dataset of Complete Systematic Screening Protocol for the Stomach*. DOI: [10.6084/m9.figshare.27308133](https://doi.org/10.6084/m9.figshare.27308133). Licencia: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Los nombres y licencias corresponden a los registros de Figshare enlazados. Las imágenes se conservan bajo sus licencias originales; el código y los pesos del modelo tienen la licencia indicada en el README del proyecto.
